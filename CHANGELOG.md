# Change Log

All notable changes to the "sate-ai-vscode" extension will be documented in this file.

## [0.1.0] - 2026-09-01

- Initial release of **SATE AI - AI Model Testing** for VS Code.
- Run stress tests on edge AI models directly from the Command Palette.
- Golden baseline saving and report viewing integration.
- Right-click context menu integration for `.gguf`, `.tflite`, and `.onnx` files.
- Status bar status indicators and live execution logging.
